# Starter scripts

Copy the C# files into a Unity 6 LTS project at the same paths.

- Core/IDamageable.cs: combat interface.
- Heroes/HeroHealth.cs: health and defeat events.
- Heroes/MOBAHeroController.cs: simple WASD movement using CharacterController.
- Combat/BasicMeleeAttack.cs: press Space to attempt a short-range attack.

The scripts are starter code and have not yet been compiled in the Unity Editor in this repository. Use Docs/UNITY_SETUP.md to create a test scene and verify them. For this first prototype, set Active Input Handling to Input Manager (Old) or Both.
